## ۶. جلوگیری از Data Leakage

### ⚠️ قانون حیاتی: `casual` و `registered` هرگز به عنوان Feature استفاده نمی‌شوند

**دلیل:**
```
cnt = casual + registered
```

متغیرهای `casual` (اجاره‌های کاربران غیرعضو) و `registered` (اجاره‌های کاربران عضو) اجزای تشکیل‌دهنده متغیر هدف هستند. استفاده از آن‌ها به عنوان ورودی مدل به معنای **دادن جواب به مدل** است.

هر مدلی که از این متغیرها استفاده کند، R² نزدیک به ۱ خواهد داشت، اما این عملکرد **تقلبی** است و در دنیای واقعی قابل استفاده نیست — زیرا قبل از وقوع روز، تعداد اجاره‌های casual و registered مشخص نیست.

### سایر اقدامات جلوگیری از نشت اطلاعات

- **`instant`** (شناسه ردیف) و **`dteday`** (تاریخ) به عنوان Feature استفاده نمی‌شوند
- **تقسیم زمانی:** داده‌ها به صورت زمانی (نه تصادفی) تقسیم می‌شوند
- **Scaling:** اگر StandardScaler استفاده شود، فقط روی داده‌های آموزشی fit می‌شود

- پاییز بیشترین و بهار کمترین میانگین تقاضا را دارد
- هوای صاف با تقاضای بالاتر همراه است

## ۱۰. مدل‌های یادگیری ماشین

### ۱۰.۱ رگرسیون خطی ساده (Linear Regression)

ساده‌ترین مدل: تنها از `temp` برای پیش‌بینی `cnt` استفاده می‌کند.

### ۱۰.۲ رگرسیون چندجمله‌ای درجه ۲ (Polynomial Regression — Degree 2)

تبدیل ویژگی `temp` به `[temp, temp²]` و سپس رگرسیون خطی. این مدل می‌تواند رابطه غیرخطی (منحنی) بین دما و تقاضا را نشان دهد.

### ۱۰.۳ رگرسیون چندجمله‌ای درجه ۳ (Polynomial Regression — Degree 3)

تبدیل `temp` به `[temp, temp², temp³]`. بررسی اینکه آیا پیچیدگی بیشتر بهبود قابل توجهی ایجاد می‌کند.

### ۱۰.۴ رگرسیون خطی چندگانه (Multiple Linear Regression)

استفاده از ۶ متغیر: `temp, hum, windspeed, yr, workingday, holiday`

### ۱۰.۵ رگرسیون خطی چندگانه + StandardScaler

همان مدل ۱۰.۴ ولی با نرمال‌سازی ویژگی‌ها. StandardScaler **فقط روی Train** تنظیم (fit) می‌شود.

---

## ۱۱. ارزیابی مدل‌ها

معیار ارزیابی: **R² (ضریب تعیین)**

- **R² = 1:** مدل کاملاً داده‌ها را توضیح می‌دهد
- **R² = 0:** مدل به اندازه میانگین ساده عمل می‌کند
- **R² < 0:** مدل بدتر از پیش‌بینی میانگین عمل می‌کند

R² منفی در مدل‌های تک‌متغیره به دلیل **تغییر توزیع** بین دوره آموزش و آزمون رخ می‌دهد — تقاضا در اواخر ۲۰۱۲ (دوره آزمون) به‌طور محسوسی بالاتر است.

|-----|----------|---------|

| Polynomial Degree 2 (temp) | ۰.۵۰۸۰ | -۰.۳۱۷۵ |
| Polynomial Degree 3 (temp) | ۰.۵۲۰۹ | -۰.۳۱۳۸ |

| Multiple Regression + Scale | ۰.۷۵۰۲ | ۰.۴۰۰۰ |

> **توجه:** R² منفی در مدل‌های تک‌متغیره ناشی از تغییر توزیع زمانی (distribution shift) است، نه overfitting.

## ۱۳. نتایج و یافته‌های مهم

1. **دما مهم‌ترین متغیر** برای پیش‌بینی تقاضاست، اما به‌تنهایی کافی نیست
2. **مدل چندگانه** با اضافه کردن `yr` (ترند سالانه) عملکرد بسیار بهتری دارد
3. **R² Train = ۰.۷۵** و **R² Test = ۰.۴۰** نشان می‌دهد مدل چندگانه ۷۵٪ واریانس آموزشی و ۴۰٪ واریانس آزمونی را توضیح می‌دهد
4. **تغییر توزیع زمانی** بین دوره Train و Test باعث افت R² آزمونی می‌شود
5. **Scaling** تأثیری بر R² مدل خطی ندارد (OLS ذاتاً مقیاس‌ناپذیر است)
6. **هوای صاف، دمای بالا، و رطوبت پایین** با تقاضای بیشتر همراه هستند
